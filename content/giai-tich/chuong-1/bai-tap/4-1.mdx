<De>
Với mỗi tập sau, cho ba cận trên nếu có; nếu không, kết luận không bị chặn trên.

Các tập được xét (cùng ký hiệu với bài 4.1):

| Ý | Tập |
| --- | --- |
| a | $[0,1]$ |
| b | $(0,1)$ |
| c | $\{2,7\}$ |
| d | $\{\pi,e\}$ |
| e | $\{1/n:n\ge1\}$ |
| f | $\{0\}$ |
| g | $[0,1]\cup[2,3]$ |
| h | $\bigcup_{n\ge1}[2n,2n+1]$ |
| i | $\bigcap_{n\ge1}[-1/n,1+1/n]$ |
| j | $\{1-1/(3n):n\ge1\}$ |
| k | $\{n+(-1)^n/n:n\ge1\}$ |
| l | $\{r\in\mathbb Q:r<2\}$ |
| m | $\{r\in\mathbb Q:r^2<4\}$ |
| n | $\{r\in\mathbb Q:r^2<2\}$ |
| o | $\{x\in\mathbb R:x<0\}$ |
| p | $\{1,\pi/3,\pi^2,10\}$ |
| q | $\{0,1,2,4,8,16\}$ |
| r | $\bigcap_{n\ge1}(1-1/n,1+1/n)$ |
| s | $\{1/p:p\in\mathbb P\}$, với $\mathbb P$ là tập số nguyên tố |
| t | $\{x\in\mathbb R:x^3<8\}$ |
| u | $\{x^2:x\in\mathbb R\}$ |
| v | $\{\cos(n\pi/3):n\ge1\}$ |
| w | $\{\sin(n\pi/3):n\ge1\}$ |
</De>

<LoiGiai>

**Bước 1. Đọc dữ kiện.**

Xét các giả thiết và ký hiệu trong đề; $n$ chạy qua các số nguyên dương nếu không ghi khác.

**Bước 2. Xác định yêu cầu.**

Ba cận trên của từng tập. Cần xử lý từng ý trong đề.

**Bước 3. Chọn kiến thức.**

Cận trên không cần thuộc tập. Nếu $M$ là cận trên thì $M+1,M+2$ cũng là cận trên.

**Bước 4. Giải từng bước.**

Bảng dưới ghi đầu mút của từng tập để kiểm tra cận:

| Ý | $\inf$ | $\sup$ |
| --- | --- | --- |
| a, b | $0$ | $1$ |
| c | $2$ | $7$ |
| d | $e$ | $\pi$ |
| e | $0$ | $1$ |
| f | $0$ | $0$ |
| g | $0$ | $3$ |
| h | $2$ | $+\infty$ |
| i | $0$ | $1$ |
| j | $2/3$ | $1$ |
| k | $0$ | $+\infty$ |
| l | $-\infty$ | $2$ |
| m | $-2$ | $2$ |
| n | $-\sqrt2$ | $\sqrt2$ |
| o | $-\infty$ | $0$ |
| p | $1$ | $10$ |
| q | $0$ | $16$ |
| r | $1$ | $1$ |
| s | $0$ | $1/2$ |
| t | $-\infty$ | $2$ |
| u | $0$ | $+\infty$ |
| v | $-1$ | $1$ |
| w | $-\sqrt3/2$ | $\sqrt3/2$ |

Với mỗi hàng có $\sup=M$ hữu hạn, ba cận trên là $M,M+1,M+2$. Các ý **h, k, u** không bị chặn trên: (h) chứa $2n$; (k) có $n+(-1)^n/n\ge n-1$; (u) chứa mọi bình phương $n^2$. Để xác định các hàng khó: (i) bằng $[0,1]$ vì điểm ngoài bị loại khi $n$ đủ lớn; (r) bằng $\{1\}$ vì $|x-1|<1/n$ với mọi $n$ buộc $x=1$. Tính trù mật cho các cận ở (l), (m), (n); (s) có số nguyên tố nhỏ nhất là 2. Giá trị sin/cos ở (v), (w) lặp theo chu kỳ 6.

**Bước 5. Kiểm tra.**

Ở §4, $+\infty$ trong bảng chỉ ghi nhận không bị chặn trên, không phải một cận trên thực. Ví dụ (n) có ba cận $\sqrt2,\sqrt2+1,\sqrt2+2$.

**Bước 6. Cách tự làm bài tương tự.**

Tìm đầu mút trên trước. Phân biệt hợp ở (h) với giao ở (i), (r).

</LoiGiai>
