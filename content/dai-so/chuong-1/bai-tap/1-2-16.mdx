<De>
Tìm đường tròn $x^2 + y^2 + ax + by + c = 0$ đi qua các điểm sau.

**a.** $(-2, 1)$, $(5, 0)$ và $(4, 1)$ · **b.** $(1, 1)$, $(5, -3)$ và $(-3, -3)$
</De>

<GoiY so={1}>
Mỗi điểm $(x_0, y_0)$ cho một phương trình tuyến tính theo $a, b, c$: $ax_0 + by_0 + c = -(x_0^2 + y_0^2)$.
</GoiY>

<GoiY so={2}>
Câu a: $-2a + b + c = -5$, $5a + c = -25$, $4a + b + c = -17$. Trừ PT 1 khỏi PT 3 để khử $b + c$.
</GoiY>

<LoiGiai>
**a.** Từ PT 3 − PT 1: $6a = -12$, $a = -2$. Từ PT 2: $c = -15$. Từ PT 1: $b = -5 + 2a - c = 6$.
$$x^2 + y^2 - 2x + 6y - 15 = 0 \iff (x - 1)^2 + (y + 3)^2 = 25.$$
Kiểm tra $(5, 0)$: $25 - 10 - 15 = 0$ ✓.

**b.** Ba phương trình: $a + b + c = -2$, $5a - 3b + c = -34$, $-3a - 3b + c = -18$. Giải ra $a = -2$, $b = 6$, $c = -6$:
$$x^2 + y^2 - 2x + 6y - 6 = 0 \iff (x - 1)^2 + (y + 3)^2 = 16.$$
Kiểm tra $(1, 1)$: $1 + 1 - 2 + 6 - 6 = 0$ ✓.
</LoiGiai>

<LoiHayMac>
Bỏ quên $x^2 + y^2$ khi thay số: $x^2 + y^2$ là **số đã biết** khi thay toạ độ điểm, nên phải chuyển sang vế phải.
</LoiHayMac>
